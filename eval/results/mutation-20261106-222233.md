## Reading the survivors (by hand, 2026-11-06)

**4 are equivalent: no observable change.**
- `shortest_path_weight` swap_args: `add_edge(edge[1], edge[0], ...)` on an undirected graph is the same edge.
- `compare_versions` Or -> And, and `check_version_requirement` Or -> And: inside an `isinstance(..., str)` check that cannot
  trigger, because the MCP input schema already rejects non-strings.
- `check_version_requirement` Is -> IsNot: the mutant calls `contains(v, prereleases=None)`, which is the library default.

**5 are real gaps, all in the differential test cases, not in the gates.**
- `highest_betweenness_centrality_node`, 3 mutants on line 5: the weighted branch. No differential case sets
  `weight_attribute`, so that code is never exercised.
- `compare_versions` Lt -> LtE: `a_is_less` becomes true for equal versions. No case compares two equal versions.
- `count_triangles` negate: only the plural in the `display` text flips, and the cases do not compare `display`.
