Task board

Give the agent work.
It grows the tools it needs.

When the agent lacks a capability, Zyven finds it in pinned open-source code — you approve, a verified MCP tool is compiled in a sandbox, and it's hot-loaded mid-task. Learned skills are reused forever.

⌘/Ctrl + ↵ to run

Library

Verified skills

Capabilities Zyven compiled from open-source code and kept after passing every verification gate. Each skill is an MCP tool the agent loads on demand.

Insights

Learning, measured

The first task that needs a capability pays the compile cost. Every similar task after that reuses the verified skill — this is the learning curve, live from the board.

Verification gates

Repo explorer

What could this repo become?

Pure static analysis, nothing executed: how much of a repository looks like it could be turned into MCP tools, how its modules connect, and which parts are already covered by a catalog capability. The MCP-able count is an estimate. Only the compile gates decide what is actually verified.
