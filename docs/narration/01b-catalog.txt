This is the catalog page. Each entry is a repository pinned to an exact commit, with its license and a note on what it can do. It is a curated list, and nothing outside it is ever fetched, so adding a repository is a deliberate step: one entry in a file, then a sync. Eight are in today, covering calendars, phone numbers, I D checks, math, versions and graphs. The dashboard does not care which repository a tool came from.
