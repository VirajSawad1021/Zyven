Here is what compiling actually does. Five roles take turns. The Scout finds capabilities worth wrapping. The Architect designs the tools. The Compiler writes the code. The Tester writes checks from the library, without seeing that code. And a Repair step fixes what fails. Then six gates decide. Policy checks the code only uses what it should. Import loads it cleanly. Upstream tests run the library's own test suite. Input robustness feeds equivalent inputs and expects equal answers. M C P smoke calls every tool the way an agent would. And differential compares our output with the real library, case by case.
